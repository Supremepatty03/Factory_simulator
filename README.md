# Factory Simulation

Симулятор производственной линии на C++20.

Программа моделирует обработку изделий на наборе станков в соответствии с заданными правилами:

- изделия проходят последовательность операций;
- станки имеют очереди FIFO;
- выбор следующего станка выполняется по минимальному `wait_time`;
- события выводятся в строгом порядке времени.

---

# Используемые технологии

- C++20
- STL
- CMake 3.20+
- Visual Studio Code 

---

# Обработка ошибок

При ошибке формата входного файла программа:

- выводит первую ошибочную строку;
- завершает работу.

Примеры ошибок:

- неверное количество чисел;
- отрицательные значения;
- выход за диапазон;
- лишние токены;
- некорректный формат.

---

# Ограничения

| Параметр | Ограничение |
|---|---|
| `1 ≤ M ≤ 100` | количество операций |
| `1 ≤ N ≤ 100` | количество станков |
| `0 ≤ T[i][j] ≤ 10000` | время обработки |
| Общее число изделий ≤ 100000 | суммарный лимит |

---

# Особенности реализации

## FIFO очереди

Каждый станок использует очередь FIFO:

- первое поступившее изделие обрабатывается первым.

---

## Выбор станка

Станок выбирается по:

1. минимальному `wait_time`;
2. минимальному номеру станка при равенстве.

---

## Порядок событий

При одинаковом времени события выводятся строго в порядке:

```text
finish
start
wait
ready
```
